# Student Grade Management System

A beginner-friendly Python project for managing student grades using basic data structures and functions.

## Overview

This project demonstrates how Python can be used to store student names and grades and perform basic student record operations.

## Features

- Add a student's grade
- Update an existing student's grade
- Delete a student record
- Display student records

## Technologies Used

- Python 3
- Dictionaries
- Functions
- Conditional statements
- Loops

## Project Structure

```text
Student-Grade-Management-System/
├── main.py
├── project.py
└── README.md
```

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the Python file you want to test:

```bash
python main.py
```

You can also run:

```bash
python project.py
```
